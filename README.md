# MAGNAT Emoji Studio

Студийный веб-редактор анимированных эмодзи и стикеров для Telegram (`.tgs` / Lottie `.json`) с встроенной базой из **263 анимированных эмодзи MAGNAT** (Классика — 144, Персонажи — 58, Подарки — 34, Любовь — 27).

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5180`. Сборка: `npm run build`, тесты: `npm test`.

## Возможности

- **263 эмодзи MAGNAT из 4 паков**: ленивая подгрузка превью (`IntersectionObserver`), мгновенный поиск по `#номеру` и разделам.
- **Живой редактор надписи `MAGNAT` (`Надпись`)**:
  - автоматическое распознавание слотов бренда (`tier_glyph`, `tier_text`, `mylogo`, включая 3D-слои и парные карточки) во всех 263 эмодзи;
  - замена текста `MAGNAT` на любой свой (кириллица + латиница) в векторных кривых с сохранением всех 60 fps анимаций, наклонов и привязок;
  - перекраска только надписи, добавление внешней обводки, масштаб, сдвиг X/Y, межбуквенный интервал, скрытие или возврат оригинального вектора `MAGNAT`;
  - **пакетная замена текста сразу во всём паке** одной кнопкой;
  - 5 шрифтов OFL: Montserrat Black, Unbounded, Rubik ExtraBold, Russo One, Pacifico.
- **Дерево слоёв и вложенных композиций (`precomp`)**: раскрытие `assets`, переименование, скрытие, дублирование, порядок, инспектор трансформации (позиция, масштаб, отражение, поворот, прозрачность с сохранением ключевых кадров).
- **Палитра и эффекты**: замена цветов по всему стикеру или выбранной композиции, Блеск металла, Голограмма, Глитч и Пикселизация.
- **Работа с паками (`.zip`)**: импорт/экспорт `.zip` архивов с готовыми `.tgs` файлами для `@Stickers`, проверка всех ограничений Telegram (`≤ 64 кБ`, `512×512`, `60 fps`, `≤ 3 с`) и мини-превью `40×40 px`.
