# Мастерская эмодзи

Редактор анимированных стикеров и эмодзи для Telegram (`.tgs`). Написан с нуля: свой код, свой дизайн, свои шаблоны.

## Запуск

```bash
npm install
npm run dev
```

Откроется на http://localhost:5180. Сборка для сайта: `npm run build`, готовые файлы в `dist/`.

## Что умеет

- 27 векторных шаблонов по категориям (Классика, Персонажи, Любовь, Финансы, Разное) с мгновенным поиском: сердце, смайлик, звезда, мячик, солнце, табличка с текстом, огонь, лайк, подарок, корона, молния, ракета, «100», бейдж, облачко с текстом, сияние, кубок (#1), штамп (ТОП), крутой в очках, котик с табличкой (МЯУ!), череп со светящимися глазами, обнимашки с сердечком, золотая монета ($), график роста (+100%), праздник с конфетти, знак внимания (!), пустой холст.
- Открыть `.tgs` или Lottie `.json` (кнопка или перетаскивание на холст).
- Слои и группы: показать/скрыть, переименовать (двойной клик), выше/ниже, дублировать, удалить.
- Палитра: все цвета стикера или выбранного слоя, замена цвета везде сразу, сдвиг оттенка, Ч/Б, инверсия.
- Текст: русский и английский, 3 шрифта (OFL), обводка, анимации (пульс, качание, появление, волна, тряска). Буквы превращаются в фигуры, потому что Telegram не показывает текстовые слои.
- Проверка правил Telegram: до 64 кБ, 512×512, 60 к/с, до 3 секунд, неподдерживаемые функции. Кнопки «Сжать файл» и «Обрезать до 3 с».
- Эффекты (включаются и выключаются, слои не портят; в файл попадают при скачивании):
  - пикселизация — анимация снимается по кадрам в сетку 24/32/48 и собирается из квадратов; частота кадров сама снижается, чтобы файл влез в 64 кБ;
  - блеск металла — заливки становятся металлическим градиентом с бегущим бликом;
  - глитч — красная и голубая копии дёргаются в стороны короткими вспышками;
  - голограмма — цвета переливаются радугой, тёмные обводки остаются.
  Металл, глитч и голограмму можно применить ко всему стикеру или к одному слою. Всё сделано без эффектов слоёв Lottie, которые Telegram не показывает.
- Отмена и повтор (Ctrl+Z, Ctrl+Shift+Z), удаление слоя клавишей Delete.
- Скачать `.tgs` или `.json`.

## Устройство

- `src/lib` — логика без интерфейса: формат Lottie/TGS, цвета, слои, текст, шаблоны, проверки. Тесты: `npm test`.
- `src/components` — панели редактора.
- Плеер — `lottie-web` (лёгкая сборка без выполнения выражений из файлов).
