# 🤖 Руководство по запуску Telegram Бота и Mini App (TMA)

Данное руководство позволит вам за 2 минуты подключить **MAGNAT Emoji Studio** как **Telegram Mini App** и запустить Telegram-бота для продажи подписок за **Telegram Stars (Звёзды)** без вложений и посредников.

---

## ⚡ Преимущества монетизации через Telegram Stars
1. **0 рублей начальных вложений**: бот работает бесплатно.
2. **0% риска блокировки мерчантов**: платежи идут через официальную систему Telegram Stars.
3. **Прямой вывод в Toncoin (TON)**: заработанные Stars выводятся напрямую на ваш TON-кошелек через официальную платформу [Fragment.com](https://fragment.com).
4. **Оплата в 1 клик для пользователей**: пользователи оплачивают со своего баланса Telegram, картой или Apple Pay без перехода на сторонние сайты.

---

## 📋 Шаг 1. Создание бота в @BotFather
1. Откройте официального бота [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/newbot`.
3. Введите название бота (например: `MAGNAT Emoji Studio`).
4. Введите юзернейм бота (например: `magnat_emoji_bot` или `my_emoji_studio_bot`).
5. Скопируйте полученный **HTTP API Token** (вида `123456789:ABCDEF...`).

---

## 📱 Шаг 2. Настройка кнопки меню Mini App (Menu Button)
1. В диалоге с [@BotFather](https://t.me/BotFather) отправьте команду:
   ```
   /setmenubutton
   ```
2. Выберите созданного бота.
3. Отправьте URL веб-приложения:
   ```
   https://dima11433.github.io/emoji-editor/
   ```
4. Введите текст для кнопки (например: `🎨 Редактор эмодзи` или `Открыть Studio`).

*Теперь в вашем боте в левом нижнем углу всегда будет активна кнопка вызова Mini App!*

---

## 🔗 Шаг 3. Создание прямой ссылки на Mini App (Short Name)
Чтобы делиться ссылкой на приложение вида `t.me/ваш_бот/app` в каналах и чатах:
1. В [@BotFather](https://t.me/BotFather) отправьте команду:
   ```
   /newapp
   ```
2. Выберите вашего бота.
3. Введите название приложения: `MAGNAT Emoji Studio`.
4. Введите описание и загрузите аватар/иконку (640x360 px или квадратную).
5. Введите URL:
   ```
   https://dima11433.github.io/emoji-editor/
   ```
6. Введите короткое имя (например: `studio` или `app`).
7. Вы получите постоянную ссылку: `t.me/ваш_бот/app`, по которой приложение запускается на полный экран!

---

## 💻 Шаг 4. Запуск сервера бота (для обработки команд и Stars)
В папке проекта уже лежит готовый скрипт `bot/bot.js`.

В терминале (на компьютере или любом VPS):
```bash
# Windows PowerShell
$env:TELEGRAM_BOT_TOKEN="ваш_токен_из_BotFather"
node bot/bot.js

# Linux / Mac
export TELEGRAM_BOT_TOKEN="ваш_токен_из_BotFather"
node bot/bot.js
```

### Команды бота:
- `/start` — приветственное сообщение и кнопка запуска Mini App.
- `/pro` — отправка инвойса на 290 Stars (подписка PRO на 1 месяц).
- `/vip` — отправка инвойса на 890 Stars (пожизненный VIP доступ).
- `/help` — пошаговый гайд по экспорту наборов в официальный бот @Stickers.

---

## 💰 Шаг 5. Как забирать деньги (Вывод средств)
1. В Telegram перейдите в профиль вашего бота или канал.
2. Откройте **Баланс бота** (Stars / Звёзды).
3. При накоплении от 1 000 Stars зайдите на сайт [Fragment.com](https://fragment.com).
4. Авторизуйтесь через ваш Telegram-аккаунт.
5. Нажмите **Withdraw Stars** и выведите их в **Toncoin (TON)** прямо на ваш кошелёк (Tonkeeper, Telegram Wallet).
